# 🧬 BioEmpire V13 – AI asosida ishlovchi sog‘liq platformasi

BioEmpire V13 – bu FastAPI asosida qurilgan, Gemini va Groq AI bilan integratsiyalashgan sog‘liqni saqlash va marketing platformasi.

## 🚀 Xususiyatlar

- ✅ Ro'yxatdan o'tish va kirish (JWT/sessiyasiz)
- ✅ AI chat (Gemini + Groq fallback)
- ✅ Kamera orqali rasm tahlili (Gemini Vision)
- ✅ Ovozli chat (Web Speech API)
- ✅ Ijtimoiy tarmoq (post, like, comment)
- ✅ Profil va statistika
- ✅ Paketlar (1 hafta – 10 yil)
- ✅ Admin panel (CEO / 12345678)
- ✅ AI ADS monitoring (avtonom marketing kampaniyalari)
- ✅ Ma'lumotlar JSON formatida saqlanadi

## 🔧 Texnologiyalar

- FastAPI (backend)
- Tailwind CSS (frontend)
- Google Gemini AI (asosiy)
- Groq AI (fallback)
- JSON fayl ma'lumotlar bazasi

## 🔑 API kalitlari

Render Environment Variables ga qo'shing:
- `GEMINI_API_KEY` – Google Gemini kaliti (majburiy)
- `GROQ_API_KEY` – Groq kaliti (ixtiyoriy)

## 🚀 Deploy

1. GitHub’ga yuklang
2. Render’da **New Web Service** → GitHub repo
3. **Build Command**: `pip install -r requirements.txt`
4. **Start Command**: `uvicorn main:app --host 0.0.0.0 --port $PORT`
5. Environment Variables: `GEMINI_API_KEY`, `GROQ_API_KEY`
6. Deploy tugmasini bosing
